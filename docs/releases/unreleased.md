# SKALA Attendance — 다음 릴리스

이 문서는 아직 배포 버전이 정해지지 않은 사용자 영향 변경을 세션 간 보존합니다. 이 문서의 변경만으로 릴리스가 승인되거나 시작되지는 않습니다.

## 변경 사항

- 다른 페이지로 이동한 뒤 출결 기본 화면으로 바로 돌아갈 수 있는 홈 버튼을 추가했습니다.
- 설정에 이름·지역·반을 기기 내에 저장하고, SKALA 인증 화면에서 사람 아이콘을 눌러 세 항목만 한 번에 입력할 수 있도록 했습니다. 제출과 Google 인증은 자동 실행하지 않습니다.
- 업데이트 확인 기능을 설정 메뉴로 옮겼습니다.
- 익명 사용 통계 안내는 짧은 요약을 먼저 보여주고, 상세 수집·제외 항목은 필요할 때 펼쳐볼 수 있도록 정리했습니다.
