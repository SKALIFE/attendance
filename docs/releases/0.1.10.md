# SKALA Attendance 0.1.10

## 변경 사항

- 하단의 새로고침, 업데이트 확인, 설정, 종료 동작을 간결한 아이콘 버튼으로 정리하고 한국어 도움말과 접근성 레이블을 추가했습니다.
- 설정에서 익명 사용 통계 전송 여부를 선택할 수 있으며, 수집 항목과 제외 항목을 확인할 수 있습니다.
- 웹뷰 연결 실패와 업데이트 확인·다운로드·설치 결과를 개인정보 없이 진단할 수 있도록 익명 통계를 보강했습니다.
- 계정 정보, 출결 내역, 실제 방문 주소, 페이지 내용, 쿠키, 토큰은 수집하지 않습니다.
- 출결 또는 로그인 자동화 동작에는 변경이 없습니다.
