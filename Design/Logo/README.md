# 로고 및 아이콘 기여

SKALA Attendance의 앱 아이콘과 메뉴바 아이콘을 제작합니다.

## 필요한 파일

```text
Design/Logo/
├── AppIcon.png       # 1024×1024
├── AppIcon.svg       # 원본
├── MenuBarIcon.svg   # 단색, 투명 배경
└── Preview.png       # 선택 사항
```

앱 아이콘과 메뉴바 아이콘은 같은 모티프를 사용하면 좋습니다. 메뉴바 아이콘은 작은 크기와 밝은·어두운 메뉴바에서도 알아볼 수 있도록 단순하게 표현해 주세요.

Fork에서 작업 브랜치를 만든 뒤 파일을 `Design/Logo/`에 추가하고 `main` 브랜치로 Pull Request를 보내주세요. Xcode 프로젝트와 Swift 코드는 수정하지 않아도 됩니다.
